# סוכן דיג'יי לפייסבוק 🎧

סוכן שרץ על המחשב שלך, פותח דפדפן עם החשבון שלך בפייסבוק, גולל בפיד (ובקבוצות שתבחר),
ומחפש פוסטים של אנשים שמחפשים דיג'יי. על כל פוסט כזה:

1. **מגיב על הפוסט**
2. **שולח לכותב הודעה במסנג'ר**

הסוכן פועל **רק על פוסטים שעלו בשבוע האחרון**. אם פוסט ישן יותר משבוע, או שאי אפשר לדעת מתי הוא עלה, הוא מדלג עליו.
הסוכן גם זוכר למי כבר שלח, כדי לא לשלוח פעמיים לאותו פוסט או לאותו אדם.

## התקנה (פעם אחת)

1. להתקין Python 3.10 ומעלה מ-https://www.python.org/downloads/ (ב-Windows לסמן ✔ ‏"Add Python to PATH").
2. לפתוח טרמינל (CMD) בתיקייה של הפרויקט ולהריץ:

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

## הפעלה

```bash
python run.py
```

ב-Windows אפשר פשוט ללחוץ פעמיים על `run.bat`.

- בהפעלה הראשונה ייפתח דפדפן. **צריך להתחבר לפייסבוק ידנית** פעם אחת, וההתחברות נשמרת בתיקייה `browser_profile`.
- הסוכן מתחיל לגלול. כשהוא מוצא פוסט מתאים, הוא מציג אותו בטרמינל.

### מצבי עבודה (`mode` בקובץ `config.yaml`)

| מצב | מה קורה |
|---|---|
| `dry_run` | רק מחפש ומציג את הפוסטים שמצא, **לא שולח כלום**. מומלץ להתחיל ככה כדי לבדוק שהזיהוי טוב |
| `confirm` | (ברירת מחדל) לפני כל פוסט שואל: `y` לשלוח הכל, `c` רק תגובה, `m` רק הודעה, `n` לדלג, `q` לצאת |
| `auto` | שולח לבד בלי לשאול |

אפשר גם לבחור מצב משורת הפקודה: `python run.py --mode dry_run`

## הגדרות (`config.yaml`)

- `comment_text` / `messenger_text`: נוסח התגובה וההודעה. `{name}` מוחלף בשם הפרטי של כותב הפוסט.
- `max_post_age_days: 7`: גיל מקסימלי של פוסט.
- `sources`: אילו עמודים לסרוק. מומלץ להוסיף קבוצות של חתונות או אירועים באזור שלך, כי שם רוב הבקשות לדיג'יי.
- `max_comments_per_run` / `max_messages_per_run`: כמה תגובות והודעות לכל היותר בכל הרצה.
- `delay_between_actions`: המתנה אקראית בין פעולות.
- `include_patterns` / `exclude_patterns`: אם רוצים לשנות את הביטויים שמזהים פוסט מתאים.

## ⚠️ חשוב לדעת

- **פייסבוק אוסרת אוטומציה בתנאי השימוש.** יש סיכון שהחשבון יוגבל או ייחסם, במיוחד אם שולחים הרבה הודעות לאנשים שאינם חברים.
  לכן ההגדרות שמרניות: עד 5 הודעות בהרצה, עם המתנה של 45 עד 120 שניות בין פעולות. **לא מומלץ להעלות אותן הרבה.**
- הודעה לאדם שאינו חבר שלך מגיעה אצלו ל"בקשות הודעה".
- פייסבוק משנה את מבנה האתר מדי פעם. אם הסוכן מפסיק למצוא פוסטים או לא מצליח להגיב, כנראה צריך לעדכן את הסלקטורים ב-`fb_dj_agent/agent.py`.
- לוג של כל הפעולות נשמר ב-`dj_agent.log`, והיסטוריה ב-`dj_agent.db`.
