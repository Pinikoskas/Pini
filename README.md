# סוכן דיג'יי לפייסבוק 🎧

סוכן שרץ על המחשב שלך, פותח דפדפן עם החשבון שלך בפייסבוק, גולל בפיד ובקבוצות שלך,
ומחפש פוסטים של אנשים שמחפשים דיג'יי. **כל פוסט כזה נשלח אליך לווצאפ**, עם הטקסט, השם, מתי הוא עלה וקישור.
ככה אתה פונה לאנשים בעצמך, בהודעה אישית.

- הסוכן שולח **רק פוסטים שעלו ב-3 הימים האחרונים**. אם פוסט ישן יותר, או שאי אפשר לדעת מתי הוא עלה, הוא מדלג עליו.
- כל פוסט נשלח אליך פעם אחת בלבד.
- הסוכן סורק מחדש כל שעה, כל עוד החלון פתוח (`run_every_minutes`).
- בפייסבוק הסוכן **רק קורא**: הוא לא מגיב, לא שולח הודעות ולא מפרסם כלום.

## התקנה (פעם אחת)

1. להתקין **Node.js** (גרסת LTS) מ-https://nodejs.org
2. לפתוח CMD בתיקייה של הפרויקט ולהריץ:

```bash
npm install
```

הפקודה מתקינה את הספריות ואת דפדפן Chromium.

## חיבור לווצאפ (פעם אחת)

ההודעות נשלחות **מהווצאפ שלך אליך**, לצ'אט "אני" (הצ'אט עם עצמך), דרך **ווצאפ ווב** שהסוכן פותח בלשונית נוספת באותו דפדפן.

1. ב-`config.yaml` מלא את המספר שלך תחת `whatsapp` → `phone` (למשל `0501234567`).
2. הרץ `node index.js --test-whatsapp` (או מלא את המספר בפאנל).
3. בפעם הראשונה תיפתח לשונית ווצאפ ווב עם קוד QR. סרוק אותו מהטלפון: ווצאפ → **מכשירים מקושרים** → **קישור מכשיר**.
4. אמורה להגיע אליך הודעת בדיקה. מעכשיו ההתחברות נשמרת, ואין צורך לסרוק שוב.

## הפעלה – תוכנת הבקרה

**פעם אחת** יוצרים אייקון בשולחן העבודה:

```bash
node index.js --create-shortcut
```

מעכשיו מפעילים בלחיצה כפולה על האייקון **"סוכן הדיג'יי"** בשולחן העבודה.
נפתח **חלון תוכנה** משלו, בלי שורת כתובת ובלי לשוניות, עם אייקון בשורת המשימות. הסוכן רץ ברקע, בלי חלון שחור.
**סגירת החלון סוגרת את התוכנה:** הסוכן מסיים את הפוסט שהוא באמצעו ונעצר.
לחיצה כפולה על האייקון כשהתוכנה כבר פתוחה פשוט מציגה את החלון שלה.

(אפשר גם `node index.js` או `run.bat`: אותו חלון, אבל עם חלון שחור לצידו. נוח לראות שגיאות.)

בפאנל אפשר:
- **להפעיל ולעצור** את הסוכן. "מצב בדיקה" סורק ומציג בלוג בלי לשלוח לווצאפ.
- לראות **מה הסוכן עושה עכשיו:** איזו קבוצה הוא סורק, מתי הסבב הבא וכמה פוסטים נשלחו.
- לשנות **הגדרות:** מספר טלפון, כמה ימים אחורה, כל כמה דקות לסרוק, גלילות בפיד ובקבוצות.
- **להפעיל או לכבות קבוצות** עם מתג, לחפש קבוצה, ולייבא קבוצות חדשות מפייסבוק.
- לקרוא את **הלוג** בזמן אמת, ולראות את **הפוסטים האחרונים שנשלחו** אליך, עם קישור לכל אחד.
- **לנקות את הלוג** בכפתור 🧹 נקה. רק התצוגה בפאנל מתנקה, והקובץ `dj_agent.log` נשמר.
- **למחוק פוסטים מההיסטוריה** (✕ ליד פוסט, או "מחק את כל ההיסטוריה"). פוסט שנמחק ועדיין חדש יישלח אליך שוב.
- לראות את **הפוסט האחרון שנשמר בכל קבוצה**: שם הקבוצה, מתי נבדקה וקישור לפוסט. אפשר למחוק סימון של קבוצה (✕) או את כולם, ואז הקבוצה תיסרק מההתחלה בסבב הבא.
- לקרוא **"מה הבוט עושה"**: הסבר קצר על כל היכולות של הסוכן.

כל שינוי נשמר מיד ב-`config.yaml` או ב-`groups.txt`. אם הסוכן באמצע סבב, השינוי יחול **מהסבב הבא**.

- בהפעלה הראשונה **צריך להתחבר לפייסבוק ידנית** בחלון הדפדפן של הסוכן. ההתחברות נשמרת בתיקייה `browser_profile`.
- אפשר גם בלי הפאנל: `node index.js --no-panel` (הסוכן רץ ישר בחלון השחור), `node index.js --dry-run` (בדיקה בלי שליחה), `node index.js --import-groups`, `node index.js --test-whatsapp`.

## ייבוא הקבוצות שלך

```bash
node index.js --import-groups
```

הסוכן פותח את רשימת הקבוצות שאתה חבר בהן, גולל עד הסוף ושומר את כולן בקובץ `groups.txt`, שורה לכל קבוצה עם השם שלה.
מעכשיו כל הקבוצות בקובץ נסרקות בכל סבב.

- **לכבות קבוצה:** פותחים את `groups.txt` ומוסיפים `#` בתחילת השורה שלה. עדיף על מחיקה: קבוצה שנמחקה תחזור בייבוא הבא, וקבוצה עם `#` תישאר כבויה.
- **הצטרפת לקבוצות חדשות?** מריצים שוב `--import-groups`. רק הקבוצות החדשות יתווספו, ומה שכיבית יישאר כבוי.
- **סריקה חכמה:** בפעם הראשונה הסוכן סורק כל קבוצה עד שהוא מגיע לפוסטים ישנים מ-`max_post_age_days`. הוא זוכר את הפוסט הכי חדש שבדק בקבוצה, בקובץ `groups_last_seen.json`, עם שם הקבוצה, הפוסט ומתי נבדק.
  מהסבב הבא הוא עוצר ברגע שהוא מגיע לפוסט הזה, ולכן בודק רק את הפוסטים שנוספו מאז. בדרך כלל אלה כמה פוסטים בודדים.
  - הפוסט הכי חדש נבחר לפי התאריך, כך שפוסט נעוץ ישן בראש הקבוצה לא מבלבל את הסוכן.
  - אחרי כל קבוצה הסוכן בודק אם הפוסטים באמת הגיעו מהחדש לישן, וכותב `✔ הקבוצה מסודרת מהחדש לישן` או `⚠ הקבוצה לא מסודרת לפי זמן`.
  - אם שליחה לווצאפ נכשלה בקבוצה, הסימון לא מתקדם, והפוסט ייבדק שוב בסבב הבא.
  - במצב בדיקה (`--dry-run`) הסימון לא משתנה.
  - כדי לסרוק קבוצה מחדש מההתחלה, מוחקים את הסימון שלה בפאנל ("הפוסט האחרון שנשמר בכל קבוצה" → ✕).

## הגדרות (`config.yaml`)

- `max_post_age_days: 3`: גיל מקסימלי של פוסט בימים (כולל). למשל 2 = רק פוסטים מהיומיים האחרונים.
- `whatsapp` → `phone`: המספר שלך.
- `run_every_minutes`: כל כמה דקות לסרוק מחדש (0 = פעם אחת).
- `feed_scrolls`: כמה פעמים לגלול בפיד הראשי (ברירת מחדל 40). הפיד אינסופי ולא מסודר לפי זמן, ולכן הוא נסרק לפי מספר גלילות.
- `groups_file` / `groups`: קבוצות שאתה חבר בהן. הן ממוינות מהחדש לישן ונסרקות עד שמגיעים לפוסטים ישנים (ראה "ייבוא הקבוצות שלך").
- `max_scrolls_per_group`: הגבלת ביטחון על מספר הגלילות בקבוצה.
- `delay_between_scrolls`: כמה שניות לחכות בין גלילות.
- `include_patterns` / `exclude_patterns`: אם רוצים לשנות את הביטויים שמזהים פוסט מתאים.
- `panel_port`: הפורט הפנימי של תוכנת הבקרה (ברירת מחדל 3210). לשנות רק אם תוכנה אחרת כבר משתמשת בו.
- `terminal_hebrew_fix`: החלון השחור של Windows מציג עברית הפוכה, ולכן הסוכן הופך את הטקסט שהוא מדפיס לשם, כדי שתקרא אותו נכון. ריק = אוטומטי (רק ב-Windows), `true` = תמיד, `false` = אף פעם. הקובץ `dj_agent.log` נשמר תמיד בעברית רגילה.

## חשוב לדעת

- פייסבוק משנה את מבנה האתר מדי פעם. אם הסוכן מפסיק למצוא פוסטים, כנראה צריך לעדכן את הסלקטורים ב-`src/agent.js`.
- אם הסוכן רץ על שני מחשבים בו-זמנית, כל פוסט יגיע פעמיים, כי כל מחשב זוכר רק את מה שהוא שלח.
- לוג של כל הפעולות נשמר ב-`dj_agent.log`, היסטוריית השליחות ב-`history.json`, והפוסט האחרון שנבדק בכל קבוצה ב-`groups_last_seen.json`.
