# סוכן דיג'יי לפייסבוק 🎧

סוכן שרץ על המחשב שלך, פותח דפדפן עם החשבון שלך בפייסבוק, גולל בפיד, בתוצאות חיפוש ובקבוצות שתבחר,
ומחפש פוסטים של אנשים שמחפשים דיג'יי. **כל פוסט כזה נשלח אליך לווצאפ**, עם הטקסט, השם, מתי הוא עלה וקישור.
ככה אתה פונה לאנשים בעצמך, בהודעה אישית.

הסוכן פועל **רק על פוסטים שעלו בשבוע האחרון**. אם פוסט ישן יותר משבוע, או שאי אפשר לדעת מתי הוא עלה, הוא מדלג עליו.
כל פוסט נשלח אליך פעם אחת בלבד. הסוכן יכול לרוץ ברקע ולסרוק מחדש כל שעה (`run_every_minutes`).

כברירת מחדל הסוכן **רק קורא** בפייסבוק. אפשר להפעיל גם תגובה אוטומטית על הפוסט והודעה במסנג'ר לכותב
(`send_comment` / `send_messenger`), אבל זה מעלה את הסיכון לחסימה (ראה למטה).

## חיבור לווצאפ (פעם אחת)

ההודעות נשלחות דרך **CallMeBot**, שירות חינמי שמאפשר לשלוח הודעות ווצאפ למספר שלך.
שים לב: התוכן של הפוסטים עובר דרך השרתים שלו בדרך אליך.

1. היכנס ל-https://www.callmebot.com/blog/free-api-whatsapp-messages/ ושמור באנשי הקשר את מספר הבוט שמופיע שם.
2. שלח לבוט בווצאפ: `I allow callmebot to send me messages`
3. הבוט יענה עם קוד (apikey).
4. ב-`config.yaml` מלא תחת `whatsapp` את `phone` (למשל `+972501234567`) ואת `apikey`.
5. בדיקה: `node index.js --test-whatsapp`. אמורה להגיע אליך הודעת בדיקה.

## התקנה (פעם אחת)

1. להתקין **Node.js** (גרסת LTS) מ-https://nodejs.org
2. לפתוח CMD בתיקייה של הפרויקט ולהריץ:

```bash
npm install
```

הפקודה מתקינה את הספריות ואת דפדפן Chromium.

## הפעלה

```bash
node index.js
```

ב-Windows אפשר פשוט ללחוץ פעמיים על `run.bat`. בפעם הראשונה הוא גם מריץ את ההתקנה.

- בהפעלה הראשונה ייפתח דפדפן. **צריך להתחבר לפייסבוק ידנית** פעם אחת, וההתחברות נשמרת בתיקייה `browser_profile`.
- הסוכן מתחיל לגלול. כשהוא מוצא פוסט מתאים, הוא מציג אותו בחלון השחור.

### מצבי עבודה (`mode` בקובץ `config.yaml`)

| מצב | מה קורה |
|---|---|
| `dry_run` | רק מחפש ומציג את הפוסטים שמצא, **לא שולח כלום**. מומלץ להתחיל ככה כדי לבדוק שהזיהוי טוב |
| `confirm` | (ברירת מחדל) לפני כל פוסט שואל: `y` לשלוח הכל, `c` רק תגובה, `m` רק הודעה, `n` לדלג, `q` לצאת |
| `auto` | שולח לבד בלי לשאול |

אפשר גם לבחור מצב משורת הפקודה: `node index.js --mode dry_run`

## הגדרות (`config.yaml`)

- `comment_text` / `messenger_text`: נוסח התגובה וההודעה. `{name}` מוחלף בשם הפרטי של כותב הפוסט.
- `max_post_age_days: 7`: גיל מקסימלי של פוסט.
- `sources`: אילו עמודים לסרוק. מומלץ להוסיף קבוצות של חתונות או אירועים באזור שלך, כי שם רוב הבקשות לדיג'יי.
- `max_comments_per_run` / `max_messages_per_run`: כמה תגובות והודעות לכל היותר בכל הרצה.
- `delay_between_actions`: המתנה אקראית בין פעולות.
- `include_patterns` / `exclude_patterns`: אם רוצים לשנות את הביטויים שמזהים פוסט מתאים.

## ⚠️ חשוב לדעת

- **פייסבוק אוסרת אוטומציה בתנאי השימוש.** יש סיכון שהחשבון יוגבל או ייחסם, במיוחד אם שולחים הרבה הודעות לאנשים שאינם חברים.
  לכן ההגדרות שמרניות: עד 5 הודעות בהרצה, עם המתנה של 45 עד 120 שניות בין פעולות. **לא מומלץ להעלות אותן הרבה.**
- הודעה לאדם שאינו חבר שלך מגיעה אצלו ל"בקשות הודעה".
- פייסבוק משנה את מבנה האתר מדי פעם. אם הסוכן מפסיק למצוא פוסטים או לא מצליח להגיב, כנראה צריך לעדכן את הסלקטורים ב-`src/agent.js`.
- לוג של כל הפעולות נשמר ב-`dj_agent.log`, והיסטוריית השליחות ב-`history.json`.
